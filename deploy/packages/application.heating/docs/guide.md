Build guide / 构建记录
1. Scope / 范围：先用模拟设备，楼宇、区域、控制器和回路共用逻辑设备/点名；原始采样不变成业务记录。
2. Model / 建模：将异常、告警与维修单放在同一 Build 事务；维修确认使用原 Flow。通行证是业务对象，不是平台角色。
3. Deliver and connect / 交付与接入：先生成草稿并沿原候选发布；外部网关、通知端点和模型不阻断交付。安装后配置 heatingfield、propertyfeed 与实际可用模型，再显式试读或运行真实评估；未配置时对应功能保持不可用。
4. Use / 使用：可选运行 heatingdemo 与三个普通业务计划的隔离试验；演示业务记录须由人员显式经原创建动作建立，不是安装或发布前置。在楼宇、设备、告警、门禁和健康页处理业务。
5. Reuse / 复用：第二城市只换连接环境与模拟初值，同一应用定义不复制、不改代码。
