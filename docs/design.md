# 审美

这份文档回答：界面该给人什么感觉，凭什么判断一个界面好不好看，什么东西不许出现。
结构与操作在 [ux](ux.md)。负责人在浏览器里判断观感时，用的就是这一份。

## 三个字：静、密、准

这是一件每天要盯八小时的工作用具，不是展示品。

- 静：界面自己不说话。底色中性，装饰为零；屏幕上最亮的东西是数据和那一个主动作。
- 密：一屏看到足够多的行与字段，不靠翻页与展开找东西；密但不挤，靠对齐与节奏撑住。
- 准：每个像素都有来处。间距、字号、颜色、圆角只取主题的令牌，没有“差不多”。

要像的：Linear 的安静与快，Stripe 后台的数据密度，Frappe CRM 的列表加记录。
不要像的：满屏灰框的老式 ERP，卡片套卡片的后台模板，五颜六色的统计大屏。

## 十条原则

每条后面是检验它的办法。

1. 内容先于外壳。导航、边框、分隔线都退后。检验：眯起眼睛看，先看到的是数据，不是框。
2. 层级靠字，不靠框。用字号、字重与次要色区分主次，一个区域至多三级文字：标题、正文、辅助。
   检验：去掉所有边框与底色，层级仍然读得出来。
3. 一屏一个强调。强调色只给主动作、选中态与链接。检验：一屏里数得出的强调色块不超过一处主按钮。
4. 行，不是卡片。成批的数据是通栏的行，用分隔线；卡片只给看板的卡、仪表盘的块与设置的分组。
   检验：没有哪个分节只是为了“好看”而被包进卡片。
5. 对齐就是秩序。页头、筛选栏、表格的左边缘在同一条线上；数字右对齐并用等宽数字。
   检验：从上到下拉一条竖线，没有东西无故凸出或缩进。
6. 状态有形状。状态用圆点或标签，带固定的语义色（进行、完成、警示、危险、中性）；徽章只表示数量。
   从不只靠文字颜色表达状态。检验：黑白打印后仍分得清状态。
7. 空与等也是界面。空状态教人做第一步；加载是与内容同形的骨架，不是空白中间一个转圈。
8. 动得有理由。动效只说明空间关系：对话框从哪来，卡片拖到哪。时长取主题令牌，遵循系统的“减少动态效果”。
9. 明暗同等。亮色与暗色都要像是特意设计的。检验：每个界面两种模式各看一眼。
10. 文字是界面的一半。标签准确，数值经过格式化，不出现内部的键、编号与英文占位。

## 主题与令牌

- 组件只来自 Astryx，主题用官方的 `neutral`。换主题由负责人决定，全产品只有一个。
- 品牌只经主题表达：颜色、字体、圆角在主题里定一次。页面里从不写具体的颜色与尺寸。
- 页面的框架、留白与栅格取自官方模板，改造时不动（[frontend](frontend.md)）。
- 图标只用一套：官方模板所用的 Heroicons 线性图标。只有图标的按钮必须带可读的名称。
- 密度由应用类别统一设定：工具应用紧凑，业务应用适中。页面不自选密度。

## 数据怎样显示

界面是否显得粗糙，多半取决于这一节。

| 数据 | 显示 |
|---|---|
| 选项值 | 显示它的标题，不显示键；作为状态时用带语义色的标签 |
| 金额与数量 | 千分位，等宽数字，右对齐；金额带币种 |
| 日期与时间 | 列表里用相对时间，悬停给出绝对时间；记录页用成员设定的日期格式 |
| 人 | 头像加名字，不显示账号标识 |
| 引用 | 被引用记录的显示名，可点；悬停看摘要 |
| 标识 | 资源标识、接口名、编号用等宽字、次要色，从不作标题 |
| 长文本 | 列表里截成一行，悬停或点开看全文 |
| 空值 | 留空，不写“无”“N/A”或“null” |
| 布尔 | 列表里是对勾或留空，表单里是开关 |

## 不许出现

这些是机器写界面时最容易犯的毛病，出现任何一条就退回。

- 卡片套卡片；为每个分节包一层卡片。
- 渐变、发光、毛玻璃、装饰性插画；拿表情符号当图标。
- 一行里堆好几种颜色的徽章。
- 工具页面里出现居中大标题加副标题的营销式页头。
- 一屏多个主按钮；表格里一整列按钮。
- 自己发明的间距、圆角、阴影与颜色；两种风格的图标混用。
- 整页转圈的加载；闪一下又变的布局。
- 没有人据以做决定的统计卡片与图表。
- 原始 JSON、内部键、UUID 出现在标题或正文的位置。
- 中英文混杂的界面：英文界面里冒出中文，或反过来。

## 负责人怎样看

每一行做完，负责人按这六步看，每步几秒钟。哪一步不对，直接说哪一步。

1. 第一眼：三秒内说得出我在哪、这页的主角是什么、我能做的主要一件事是什么。
2. 眯眼：虚着看，焦点只有一个，没有一片片的框。
3. 换一个类型：打开另一类记录，结构完全一样，只是字段不同。
4. 换暗色：没有发灰的字、看不见的分隔线、刺眼的块。
5. 缩窄窗口：内容收拢而不是被截断或横向滚动。
6. 换中文：没有被截断的词、没有剩下的英文、标点是全角。

登录页与将来的官网是唯一可以有“展示感”的地方；其余界面都按本文。
