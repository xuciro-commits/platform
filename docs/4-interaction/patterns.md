# 4.12 交互模式

每个模式一节，按需写用途、构造、状态、行为、键盘、文案。实现组件名写在标题括号里；新模式先在本文登记再实现，同一需求不得有第二个实现。

## M1 页头（PageHeader）

- 用途：每个主视图的顶部；给出位置、身份与本页主操作。
- 构造：面包屑（回到列表或上级）→ 图标 + 标题 + 状态标签 → 元信息行（等宽 RID / API 名、项目、更新者与时间）→ 右侧操作区。
- 状态：标题过长截断并在悬停显示全名；加载时标题位显示骨架。
- 行为：操作区至多一个主按钮；列表页主按钮为“新建…”，资源页为保存控件（M4）。
- 键盘：面包屑可 Tab 到达；无专属快捷键。
- 文案：标题用资源显示名或列表复数名（“Object types”）；不在标题里放动词。

## M2 数据表（DataTable）

- 用途：资源列表、对象列表、运行记录、成员等任何同构集合。
- 构造：工具条（搜索、筛选、列选择、视图密度）→ 表头（排序、可调宽、可固定）→ 虚拟化行 → 页脚（总数、选择数）。批量操作条在选中时替换工具条。
- 状态：加载为 8 行骨架；空为 EmptyState；错误为表格位置的 Notice + 重试；部分字段被字段权限隐藏时列显示“受限”。
- 行为：行点击打开；Ctrl/⌘、Shift 多选；右键行菜单与 ⋯ 列一致；列宽与排序按表记忆；网格模式（可编辑表）只用于明确的批量编辑场景。
- 键盘：↑↓ 移动，Enter 打开，Space 选择，⌘C 复制选中单元格，Esc 清除筛选。
- 文案：列名用名词；空单元格显示“—”；时间用相对时间并在悬停显示绝对时间。

## M3 资源分区导航（ResourceNavigation）

- 用途：资源页的分区导航，占用应用侧栏。
- 构造：返回链接（回到列表）→ 资源身份（图标、显示名、类型）→ 分组的分区项（带计数或问题徽标）。
- 状态：当前分区高亮；有问题的分区显示警告点；无权访问的分区不显示。
- 行为：切换分区更新 URL 的分区段；不触发离开保护（同一资源的工作状态共享）。
- 键盘：侧栏内 ↑↓ 移动，Enter 切换。
- 文案：分区名用名词，与 4.4 表一致。

## M4 保存控件（ResourceControls）

- 用途：资源页头部右侧；显示保存状态，承载资源级操作。
- 构造：至多两个内联操作 → 保存状态文字 → 手动“保存”（仅在自动保存停止时）→ ⋯（其余操作、放弃更改、重新加载、归档）。新建记录时为“取消”“创建”。
- 状态：见 4.5 的六种状态；分支上归档显示为“在此分支上归档…”。
- 行为：自动保存 900ms；被拒绝时显示 Rejection 并停止自动保存；归档、放弃需确认。
- 键盘：⌘S 立即保存。
- 文案：状态用过去分词（“Saved as draft”）；不使用“提交”“发布”字样。

## M5 分支控件与审阅并保存（BranchControls）

- 用途：工具应用侧栏顶部；切换分支，汇总变更，进入审阅。
- 构造：分支选择（main + 打开或已提议的分支）→ 状态标签（Open、Proposed、Merged、Archived）→ “Changes (N)” → 主按钮“Review and save”或“Open proposal” → ⋯（新建分支、全部分支与提案、归档分支）。
- 状态：main 上无变更时主按钮隐藏；有错误的变更时主按钮可用但审阅页阻止保存并列出问题。
- 行为：审阅页按资源列出字段级差异，每项可放弃；main 上经自动检查后保存；分支上生成或更新提案。
- 键盘：⌘⇧S 打开审阅。
- 文案：“Review and save (N)”；提案标题默认取分支名。

## M6 检查器（Inspector）

- 用途：编辑当前选中项（画布节点、页面组件、表格行的详细配置）。
- 构造：标题（选中项名称 + 类型）→ 分组的字段（InspectorSection，可折叠）→ 底部危险操作。
- 状态：无选中时显示“选择一项以编辑”与该视图的整体设置；多选显示共同字段。
- 行为：修改即进入工作状态；Inspector 不自带保存按钮。
- 键盘：⌥⌘\ 切换显示；Esc 回到画布并保留选择。
- 文案：字段标签用名词短语；帮助文字放在字段下方弱化色一行，长说明进 ContextHelp。

## M7 侧边表单（Sheet）

- 用途：多字段的新建与编辑，不离开当前页。
- 构造：标题 → 字段（单列，按重要性排序）→ 底部固定按钮行（“取消”、主按钮“创建 / 保存”）。
- 状态：提交中禁用关闭与按钮；错误在字段旁与表单顶部 Notice 同时显示。
- 行为：Esc 或点击外部关闭（有未提交输入时先确认）；提交成功后关闭并 Toast，必要时打开新资源。
- 键盘：Enter 在最后一个字段提交；⌘Enter 任意位置提交。
- 文案：主按钮用动词 + 宾语（“Create object type”）。

## M8 确认对话框（Dialog）

- 用途：不可逆操作的确认；两三个字段的短输入。
- 构造：标题（动词 + 对象）→ 后果清单（会发生什么、不会发生什么、能否恢复）→ 可选的输入（如原因）→ 按钮（“取消”、危险或主按钮）。
- 状态：危险操作的按钮为 danger 色；删除重要资源时需输入名称确认。
- 行为：默认焦点在“取消”；执行中按钮显示进行中。
- 键盘：Esc 取消；Enter 只在焦点位于主按钮时执行。
- 文案：按钮重复标题动词（“Archive branch”），不用“确定”。

## M9 表单与字段（EntityForm、field.*）

- 用途：所有结构化输入。
- 构造：标签 → 控件 → 帮助或错误一行；必填在标签后标“*”；可选字段在标签后标“（可选）”只用于少数可选项。
- 状态：草稿值即时校验（数字、日期、引用）；服务端校验结果映射回字段。
- 行为：引用字段用选取（M22）；枚举 ≤ 5 项用分段或单选，> 5 项用下拉；长文本用自增高文本框。
- 键盘：Tab 顺序与视觉顺序一致。
- 文案：错误说明如何修正（“Use letters, digits and underscores”），不只说“无效”。

## M10 条件构建器（Expr）

- 用途：提交条件、行策略、筛选、自动化条件、可见性规则——所有谓词。
- 构造：条件组（全部 / 任一）→ 条件行（左值：属性或参数；运算符；右值：常量、参数、当前用户、函数结果）→ 添加条件 / 添加组 → “高级”中的表达式源码。
- 状态：类型不匹配的行标红并说明；引用已删除属性的行显示“缺失”。
- 行为：结构化与源码双向同步；保存的是 Expr，不是界面状态。
- 键盘：行内 Tab 移动，⌘Enter 添加条件。
- 文案：运算符用自然语言（“is any of”“包含任一”）。

## M11 对象集构建器（ObjectSet）

- 用途：Workshop 变量、Object Explorer 探索、函数输入、AIP 上下文中选择一组对象。
- 构造：起点对象类型 → 筛选（M10）→ 沿关系转到（Search Around）→ 集合运算（并、交、差）→ 结果预览（数量 + 前 20 行）。
- 状态：无权访问的类型不出现在起点列表；结果因标记或行策略被过滤时显示“部分对象不可见”。
- 行为：每一步即时计数；保存为探索或变量。
- 键盘：同 M10。
- 文案：步骤名用动词（“Filter”“Search around”）。

## M12 空、加载、错误、拒绝（EmptyState、Notice、Rejection）

| 状态 | 用 | 内容 |
|---|---|---|
| 空 | EmptyState | 这是什么、为什么空、主按钮产生第一条 |
| 加载 | 骨架 | 与最终布局同形；超过 10 秒显示“仍在加载”与取消 |
| 错误 | Notice danger | 发生了什么、重试；技术细节折叠 |
| 拒绝 | Rejection | 服务端原因（已翻译）、下一步建议、请求键 |
| 无权 | EmptyState | 需要什么权限、向谁申请；不显示数据的存在细节 |

- 行为：拒绝与错误不自动消失；重试保留用户输入。

## M13 就地下一步（Next steps）

- 用途：资源 Overview 与项目 Overview 上的黄金路径引导，替代向导。
- 构造：有序步骤列表（序号或完成勾、标题、一句说明、按钮）；第一个未完成的非可选步骤按钮为主按钮。
- 状态：完成的步骤弱化；不可执行的步骤禁用并说明缺什么。
- 行为：按钮直接打开对应的新建 Sheet 或目标页；完成状态从资源推导，不另存。
- 文案：步骤标题用动词短语（“Define an object type”）。

## M14 命令面板（⌘K）

- 用途：搜索与跳转的唯一入口；执行命令。
- 构造：输入框 → 分组结果（分组与前缀见 3-information §3.8）。
- 行为：≥2 字符开始查询（200ms 防抖）Enter 打开，⌘Enter 在侧窗打开。
- 键盘：↑↓ 选择，Esc 关闭。
- 文案：占位“Search or run a command…”。

## M15 菜单（ActionMenu、CommandMenu）

- 用途：⋯ 溢出菜单与右键菜单；同一对象两处菜单内容一致。
- 构造：常用操作 → 分隔 → 次要操作 → 分隔 → 危险操作（红色，最后）。
- 行为：不可用项禁用并在悬停说明原因；带快捷键的项右侧显示快捷键。

## M16 提示（Toast）

- 用途：已完成操作的反馈。
- 行为：右下角，5 秒消失，悬停暂停；可撤销的操作带“撤销”；错误不用 Toast（用 Notice 或 Rejection）。
- 文案：过去式陈述（“Object type created”）。

## M17 状态标签（Tag、StatusTag）

- 用途：状态、标记、类型等离散值。
- 色调：neutral 默认，info 进行中，success 完成，warning 需注意，danger 失败或受限；purple、pink、teal、orange 只用于分类身份（资源类型、标记以外的类别）。
- 标记固定色：internal info、confidential warning、restricted danger。
- 行为：标签不可点击；需要筛选时用表格筛选。

## M18 差异审阅（Review）

- 用途：审阅并保存、提案审阅、发布审阅、升级审阅。
- 构造：左侧变更资源列表（类型、名称、新增 / 修改 / 删除、问题数）→ 右侧字段级差异（旧值、新值；列表字段按项对比）→ 底部检查结果（自动检查、测试计划）→ 主按钮。
- 行为：逐项放弃；有阻断问题时主按钮禁用并列出问题；破坏性变更（删除属性、改类型）单独高亮并说明影响的下游。
- 文案：主按钮“Save to main”“Propose”“Merge”“Release”“Install”“Upgrade”。

## M19 画布交互（FlowCanvas、RelationCanvas）

- 用途：管道图、逻辑流、血缘、关系图、动作规则图。
- 构造：浮动工具条（添加、自动布局、缩放、适应、迷你地图）→ 节点（类型色、标题、状态徽标）→ 边（可带标签）。
- 行为：拖拽移动；从端口拖出连线；在边上插入节点；选中即进入 Inspector；双击打开节点所代表的资源；只读画布不显示添加与连线。
- 键盘：N 或 Tab 添加，Delete 删除，⌘A 全选，方向键微移，Enter 进入 Inspector，Esc 取消选择。

## M20 动作表单（业务用户执行动作）

- 用途：业务用户在对象视图、模块按钮、工作项中执行动作。
- 构造：由动作类型 Form 分区生成：标题（动作显示名）→ 参数字段（默认值、依赖显示）→ 提交条件未满足时的说明 → “取消”与以动作显示名命名的主按钮。
- 行为：提交条件在填写时即时求值并显示哪条未满足；提交后显示结果与副作用（已通知谁、已创建什么）；失败显示 Rejection。
- 文案：主按钮用动作显示名（“Approve order”），不用“提交”。

## M21 对象头与对象视图分区

- 构造：图标与类型 → 标题属性 → 3–6 个关键属性 → 状态标签 → 动作栏（主要动作 1 个 + 其余进 ⋯）。
- 分区：Overview（属性分组）、Links（按关系类型分组的小表）、Activity（编辑事实与评论时间线）、Files、Work（关联工作项）。
- 行为：关联对象点击在侧窗 inspect；属性被字段权限隐藏时显示“受限”。

## M22 选取并返回（transfer）

- 用途：在表单中选择引用（数据集、对象类型、函数、成员、对象）。
- 构造：字段显示当前值与“选择…”；点击后被调方覆盖当前视图，顶部显示“为〈字段〉选择〈类型〉”与“取消”。
- 行为：被调方可以新建再返回；返回后调用方状态完整保留；被调方只显示可选的项。

## 现存差距

- 记录类组件（RecordKanban、RecordGantt、RecordMap 等 20 余个）未按 Workshop 组件目录统一；Dialog 存在自定义宽度用法（路线图 P3.14）。
- 条件构建器 M10 与对象集构建器 M11 在各工具中的实现未统一（P3.18）。
- 差异审阅 M18 缺字段级差异与逐项放弃（P3.1）。
