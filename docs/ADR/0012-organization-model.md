# ADR-0012 — 已被企业模型取代的独立组织应用

状态：已由 [ADR-0067](0067-enterprise-modeling-layer.md) / [ADR-0068](0068-enterprise-layer-implementation.md) 的企业模型取代。组织、结构、成员与日历接口由 Enterprise 投影保留；历史角色与日志按原字节恢复。

原决定保留的语义：组织不限于一棵部门树；同一单元可处于不同法律、管理、财务、位置和项目结构，成员及关系有角色和生效时间，支持内部/外部边界与生命周期。类别由租户或行业定义，不进入内核词汇。现行元素、关系、校验与呈现归 ADR-0067/0068，不再保留独立 org 模型和旧界面的实施说明。

授权仍显式选择承载范围的结构；不能把别的结构成员关系当成业务权限。原 Caller.Units、Scope.Structure 与工作日历接口沿企业投影保留，通知受众在原输入时解析并保存，不在重放时重新解释组织。历史身份兼容与授权的具体范围归 [ADR-0105](0105-one-authorization-engine.md) 和原宿主读取路径。
