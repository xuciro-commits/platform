# ADR-0040: 关系、动作与应用组合的统一语义模型

**状态：** 已接受 (2026-09-28, #138)。项目负责人授权直接执行或在对抗性自审后执行；D1–D4 连同下述实现边界一并被接受。ADR-0031 的平台方向和 ADR-0037 的有界单记录动作保持已被接受；本决策对它们进行扩展。

## 背景

上层设计已经命名了对象**与关联 (and link)** 类型、动作/函数、页面/组件、流程/智能体、AI 函数、集成/查询以及应用/包资产（Platform.md §10.3）。而当前的构建器（Builder）导航展示的是对象、流程与访问控制、页面和应用（`web/packages/build/src/index.tsx`）。这是第一个垂直切片，而不是完整的本体 (ontology) 或应用工作室。

当前代码事实 (2026-09-28)：

| 领域 | 当前运行的内容 | 对构建者的差距 |
|---|---|---|
| 对象与关系 | `build.Object` 拥有包括一个 `reference` 在内的具类型字段；`relations.Link` 可以连接任意两条记录，`Caller.Links` 读取可见的邻居记录 | 没有具名的关联类型 (link-type) 资产、反向名称、基数/所有权规则、具类型遍历、依赖影响或关联编辑器。通用关联缺乏声明的业务含义 |
| 动作与规则 | `build.Action` 将输入、条件、同记录字段变更、生命周期转换和可选审批编译进规范的账本/工作路径 | 没有关联或其他记录的编辑、具类型结果契约、可复用的确定性函数或查询。`checkProcess` 校验引用的名称但不校验比较操作数的类型；当数值无法解析时，`holds` 会退化为文本排序 |
| 页面与交互 | 十个部件绑定到记录/动作；选中的记录和按对象的过滤器在 `ComposedPage` 内部共享；宿主在发布时检查区块 | 共享状态是硬编码的，不是具类型的变量/事件图。编辑器中缺乏关系遍历、条件可见性、可复用组件契约、模块输入/输出或依赖视图 |
| 产品与发布 | 三栏编辑器、已保存草稿与发布、生成的页面 | 对象字段和应用设置仍然使用生成的记录编辑。流程检查器将所有规则堆叠在一个长面板中。无效流程规则大多在发布时被拒绝。重新发布会替换已安装的描述符；没有不可变候选/发布版本或有状态隔离预览（#135/#136） |

一个重要区别：针对简单 `list-detail` 页面的 `PagePreview` 虚构了样例行。组合页面编辑器使用 `useHost().source` 渲染常规的 `ComposedPage`，因此它在禁用写入的同时读取构建者经授权的**实时**记录。两条路径都不是隔离的有状态模拟。`web/e2e/test-results` 中的 2026-09-28 浏览器截图展示了行为和布局，并不代表负责人对视觉质量或隔离测试环境的验收。

共同的原则是多个编写与操作界面共同消费一个**具类型的语义图**。这并不需要抄袭 Foundry，也不需要将所有平台概念塞入同一个编辑器菜单中。

## 我们的约束

- 应用 API 拥有公共资产契约和具类型代码扩展；宿主负责校验、鉴权和执行；`build` 拥有租户草稿/编辑；`relations` 拥有记录关联存储与遍历；`@platform/app` 拥有 UI 绑定，`@platform/ui` 拥有组件。不引入并行的记录/动作/关联执行器或应用私有的表达式解释器。
- 不得将业务领域词汇引入 `contract/`。业务含义驻留在具名、版本化的资产中。跨应用状态修改遵从动作与协议；一个构建器动作不能直接写入另一个应用的私有状态。
- 代码、可视化和 AI 编写在同一套资产标识、权限和发布检查上收敛。不存在任意租户代码。预览绝不调用在线效果或向生产环境写入。重放不向外部调用任何内容；已提交结果恢复和不可变修订版是独立的 #135/#136 门禁。
- 编辑器质量要求完成经实测观察的构建者任务与操作员任务，具备逼真的记录、中文支持、键盘操作与窄屏状态。单纯的浏览器测试或生成的屏幕并不代表视觉验收通过。

## 设计

1. **语义图与所有权。** 向应用 API/注册表添加 `LinkType` 资产，具备稳定的限定标识、版本、源和目标对象类型、每个遍历方向的名称、基数、必填性、权威以及删除/演进规则。`reference` 字段和通用记录关联在适当时是该契约的输入或实现，而不是其替代品。`relations` 通过宿主的规范鉴权存储/查询实例。构建器展示依赖图、其依赖关系以及某项变更会破坏什么。第一个简单的切片支持由引用支持的一对多关系；后续的多对多或带属性关联需要明确的存储/动作契约。准确记录提交时强制执行的约束。
2. **动作语义。** 保留 ADR-0037 的单记录转换作为受支持的小型用例。赋予每个动作具类型的输入/结果与效果摘要、经服务端校验的规则操作数、显式权威和失败提示消息。后续同一权威下的多记录/关联动作使用 #135 的原子已提交结果边界；跨应用工作使用已声明的协议与流程。可复用的纯函数/查询是单独命名的资产，可通过具类型输入和经授权的输出被动作、页面、AI 逻辑和代码调用。不要通过在租户端链式表单写入来伪造跨对象原子性。
3. **页面组合即绑定。** 扩展 `platform.Page`/已注册组件契约，包含具类型页面变量（选择项、过滤器、路由输入和有界派生查询）、部件输入/输出绑定和声明的事件（设置变量、导航、提交具名动作）。关联遍历绑定关联列表/详情和主/从任务。为代码页面、可视化工具和 AI 提议复用相同的绑定；在源头拒绝类型/权威/依赖错误。避免照搬 Workshop 的整个变量系统或 Appsmith 的 JavaScript 表达式。
4. **一个产品，两个创作空间。** 使用诸如**应用设计台 (Application Studio)** 之类的统领名称来代表构建者旅程，以**业务模型**（对象、关系、动作/规则、权威、数据源）和**用户体验**（应用、页面、组件、绑定）作为其主要工作区；**测试与发布**暴露校验、候选 diff、依赖关系、隔离预览和激活。“状态与动作”归属于对象行为视图内部；访问控制具备清晰的所有权/作用域视图。名称和导航属于产品文案，而非新的运行时契约。渐进式检查器优先展示常用动作路径（何时、谁、结果），然后是输入、规则、审批和高级效果；展示紧凑的前后对比/示例和内嵌行内错误。
5. **预览、发布与演进。** 诚实地将当前组合画布标记为经授权的实时数据、只读编辑视图。由独立固定数据支持的预览/模拟使用隔离的候选版本，并且可以展示拟定动作的结果而无需进行生产环境写入/效果派发。#136 拥有不可变修订版、依赖闭包和激活；本 ADR 的关联/函数/页面契约必须参与其中。重命名、删除、基数和权威变更在激活前必须报告受影响的页面、动作、AI 工具和运行中工作。
6. **使用实证。** 酒店业和制造业极简探针各自定义或复用一个对象，将其与另一个对象关联，在页面和受治理动作中使用该关系，并完成操作员任务。相同的资产在代码/API 中可发现，且仅通过声明的权限向 AI 开放。与负责人一同衡量编写完成度/错误率以及操作员任务完成度；应用特定的业务功能深度暂缓。
7. **具类型图表界面，而非图执行引擎。** `@platform/ui` 拥有基于 React Flow 的画布和受控节点目录：每种节点类型声明其类别、语义资产引用及版本（如果可用）、具名输入/输出端口、端口类型和连接容量。语义所属主件提供从其规范定义到画布节点/边的适配器，并将校验后的编辑应用回该定义。画布位置、选中状态和缩放是展示元数据；它们无法赋予执行或访问权限。目录按平台能力扩充：对象/关联拓扑、生命周期/动作、流程、AI 函数/智能体以及后续的有界媒体或物理世界模型均可以拥有各自的适配器、校验和控件。结构化对象图可以成环；生命周期可以重访状态；确定性数据流需要明确的环路/延迟规则。通用渲染器绝不能将一个图的执行语义强加给另一个图。FDE 获得节点列表、具类型连接反馈、可检查配置、依赖影响、键盘替代方案和版本化变更；客户编辑受限于已授予的节点类型。现有的只读 `Graph` 保持为操作视图。[React Flow 的自定义节点与句柄](https://reactflow.dev/learn/customization/handles)以及[连接校验](https://reactflow.dev/examples/interaction/validation)提供交互底层基座；我们的目录和宿主契约提供业务含义。

## 负责人决策点

| # | 问题 | 选项 | 推荐方案 |
|---|---|---|---|
| D1 | 具名关系是否是一等公民的版本化语义资产？ | 具有双向名称、基数和权威的 `LinkType`；或继续使用 `Field.Ref` 加上通用的 `platform.link` | 一等公民。当前的组合无法表达或校验 UI 和 AI 必须共享的业务关系。从引用支持的一对多切片和真实的强制执行语义开始。 |
| D2 | 租户编写的动作可以多大程度上改变状态？ | 仅保留同记录转换；或在 #135 之后添加同权威对象/关联编辑，而跨应用工作保持基于协议/流程 | 在原子提交边界之后添加有界的同权威编辑。针对常见用例保留简单的转换编辑器，并拒绝不支持的跨应用原子性声明。 |
| D3 | 页面部件在选择/过滤之外如何协同？ | 共享页面契约中的具类型变量与声明事件；或累积更多硬编码的部件耦合 | 具类型变量/事件，由一条基于关系的 master/detail 旅程引入。这是最小的共享契约，能够自然扩展而无需为每个部件引入新特例。 |
| D4 | FDE 如何在不碎裂平台语义的情况下编辑不同含义的图？ | 可复用的具类型节点目录与 React Flow 画布，配备按能力的适配器；或各应用自有的独立图编辑器 | 单一 UI 套件画布与目录契约。语义资产与宿主校验保持权威性；适配器负责各图的合法编辑、持久化与环路规则。首个生命周期适配器编辑现有的 `Action.From/To`，随后关系、流程与 AI 适配器跟进其平台所属主件。 |

已拒绝的方案：Foundry 形态的数据库、所有领域逻辑作为工作流、任意租户 JavaScript、第二套仅用于构建器的运行时，以及宣称当前的实时数据画布是隔离预览。现有的 ADR-0038/0039 负责人决策保持独立，并在注明处作为前提条件。

**实施前的对抗性审查 (2026-09-28)。** D1 的首个关系切片是由引用支持的，并且最初可以是只读的：展示声明绝不能暗示通用的 `platform.link` 记录或引用字段已经在强制执行具名关联的基数、删除或鉴权规则。只有当规范写入路径实际检查这些规则时，才能将它们报告为保证。D2 无法通过顺序调用两个现有动作来实现：没有 #135 的原子结果边界，可能会产生部分可见状态；跨应用工作保持为协议/流程工作。D3 的页面变量图必须在每个边缘使用调用者作用域的读取和动作声明；仅仅隐藏部件并不是访问控制规则。D4 拒绝将无类型的节点图作为新的业务解释器：渲染的节点解析为受治理的资产或具类型草稿，任何拖拽/连接手势都不得绕过现有的动作、流程或 AI 执行路径。这些限制收窄了第一批切片，而没有逆转 D1–D4。

## 后果

公共模型扩展至四种资产类型之外，因此兼容性与依赖检查变得更为严格。具名关系和具类型页面变量提升了复用性，但需要对现有的引用字段和通用关联进行深思熟虑的迁移。现有数据和 ADR-0037 行为保持有效，直到出现明确受支持的演进路径；不暗示对已发布的客户数据或在途工作进行自动重新解释。构建器可以渐进式重组，但最终完成度以整体构建和操作员旅程来评判，而非导航条目的数量。

## 实际构建 (As built)

- **21a：** 动作赋值、条件/运算符按字段类型校验；条件 Field 支持已声明的单记录引用路径，ValueField 与固定 Value 互斥，比较字段须类型兼容。工坊提供路径及比较字段选择；原动作在赋值/关联创建前通过共享 ReadRecordPath 读取相关记录，来源缺失/无权或条件失败时拒绝。审批申请及最终放行均沿原动作，放行按申请人当前权限和关联值重新校验；可选字段区分缺失与零/假。字段、状态/动作与权限共用对象编辑上下文，节点/检查器修改同一 From/To，非法连接解释原因；共享画布不执行图或持久化坐标。
- **工坊总览：** `studio.tsx` 成为构建器首页，使用完整资产清单展示对象/引用、页面、流程、函数与交付应用的关系，提供六类可点击能力入口、搜索、资产状态/版本、关联选择及现有编辑器入口；已安装代码对象进入定义视图，选中资产直接带入测试或发布审查，返回总览保留搜索与选择；图默认有界显示，搜索可定位未在初始图中的资产。不新增语义解释器或后台执行路径。
- **21b：** 引用字段 `Inverse` 声明小写具名反向关系，两端可读才显示跨应用子记录；组合表格/图表/指标按关系跟随主记录。共享页面按声明对象保留选择，关联表可选择子记录，详情、动作、历史与任务消费自己对象的选择；主记录变化清除子选择，决定后重新读取选中记录的状态/修订。关联表单显式选择关系后显示所选父记录，自动填入回指并只询问其余字段；切换父记录清除旧输入，未选择父记录或回指不可用时不创建。发布校验要求可写回指、父记录选择表格及其余必填字段；无关系绑定的独立表单仍询问父引用。提交沿子对象原有的创建动作，不授予额外权限。编辑器可配置关联对象的筛选与动作，预览保留关系/查询绑定。此Inverse路径不提供独立关系资产的基数/删除保证。首个LinkType资产、关系编辑/图投影及页面精确绑定已接通，引用支持的profile与实际保证归ADR-0046 §7.3/§14；更强关系约束仍待实施。页面变量/事件的当前实现也归ADR-0046，不以本段历史切片描述替代。
- **21c：** `Action.Creates` 在同权威一次决定中创建回指关联记录；Do 校验、After 同批写入，拒绝/追加失败不留部分结果。对象行为检查器选择已发布目标/回指字段并映射输入、固定值或现有系统来源；回指自动填写，必填映射与输入类型有前置提示，父/子赋值复用同一控件。目标创建权限仍由原宿主检查，编辑器不额外发子创建请求。`platform.NamedQuery` 被成员、页面和 AI 工具共用，按调用者权限读；候选须闭合查询依赖。跨应用原子编辑不支持。
- **页面选择绑定：** `Page.Selections{Name,Object}` 声明具类型记录变量；表格的 `Selection` 写入，详情/动作/历史/任务及函数部件读取同一变量。关联表格/图表/指标与表单的 `ParentSelection` 可引用任意已声明且有表格来源的匹配对象选择，支持单据→明细→作业；父选择变化递归清除下游选择与关联表单输入，保留无关独立选择。未具名的原对象共享选择使用同一槽位模型。编辑器提供声明与绑定，重命名同时更新草稿引用；保存、不可变候选及激活保留这些字段，变量对象进入依赖闭包。代码页面与租户页面共用区块校验；未知/错误对象类型、无表格来源、冲突父来源及选择循环拒绝发布。目录按调用者裁剪变量及引用区块，读取/动作仍由宿主授权。当前过滤仍按对象共享，不是通用标量变量或事件解释器。
- **表单参数绑定：** `Section.Inputs` 复用 `Binding` 的常量与 subject/path，路径穿过已声明的单记录引用；发布校验源/目标类型、可写字段及必填覆盖。检查器提供类型匹配的记录路径选择，绑定值在操作表单只读展示。宿主的 `Caller.ReadRecordPath` 每段复用当前主体的记录/字段读取，保留实际字段来源，页面计算及流程输入绑定使用同一方法。表单创建通过已有能力入口读取实际值，再提交原创建动作；客户端预览不成为规范参数。隐藏来源的表单不被发现，缺失/无权读取拒绝，接受结果重放使用已保存动作参数。取值绑定不替代跨对象业务约束，也不提供多记录原子写入。
- **21d：** `/v1/simulate/candidate` 从保存草稿和同构建器依赖建立空内存租户，复制显式成员/角色，最多 20 个固定时钟动作步骤；不复制生产行/日志/凭据。准备可读控制面兼容信息，步骤只用样本。发布预览将候选中准确的对象定义交给原 Build owner，投影 `candidateActions` 输入声明，测试表单复用 `PayloadFields`；常见标量/选择/引用输入可直接填写，引用只取显式测试 ID，不查询生产行。复杂、未知字段或有意无效输入保留高级 JSON，表单与 JSON 共用原计划 payload；保存/重载及执行仍走原路径。原生权限、脱敏和恢复核对生效。跨应用/审批依赖失败封闭；Flow/函数扩展归 ADR-0042/0043。
- **编辑与归档：** 对象、页面、流程、AI/代码函数与测试计划提供显式取消修改，复用 Workspace 的草稿重置，恢复已保存内容且不提交；对象字段和图节点可移除，取消也撤回这些移除。工坊检查器和编辑器通过 `@platform/app` 的原归档动作提供确认、修订检查和拒绝反馈，草稿离开活动清单但保留历史。已发布对象/页面/应用/流程/函数保留安装版本，不能用草稿归档冒充运行时退役；编译中的代码函数等待构建结果后才能归档。
- **计划与诊断：** TestPlan 用标准记录保存根、成员、输入/预期及修订；选择器只显示当前类型/资产的计划，手动切换根清除旧计划身份及根相关输入，避免保存时迁移另一资产的计划。重跑针对当前候选，输入改变清除结果，不缓存未来通过。旧 `/v1/simulate` 只读生产记录，返回仍按请求构建者权限裁剪。共享 `apiErrorMessage` 解释字符串或结构化拒绝，避免错误对象导致白屏。

证据入口：`build_actions_test.go`、`build_conditions_test.go`、`build_creates_test.go`、`definitions_test.go`、`named_query_test.go`、`simulate_candidate_test.go`、`testplan_test.go`、`simulate_test.go`；`related-page.spec.ts` 验证主/子选择、关联表单创建及动作结果，`related-create.spec.ts` 验证可视关联创建、原候选激活与操作记录结果，`page-selection.spec.ts` 验证同对象独立选择、明确父来源及激活后动作目标。浏览器保留对象/页面/动作主路径，布局和次要配置转人工。

**剩余边界：** 独立关系资产/基数/删除、标量/具名过滤/路由变量与声明事件、更广原子编辑、物理沙箱与其他适配器持久布局；业务工作台广度及整体构建发布体验仍需集中走查。编辑器的未保存保护归 ADR-0018 的共享工作区；流程布局已由 ADR-0044 接入原 Process 草稿。进程内样本隔离不是物理隔离，有界激活安装范围归 ADR-0039，不外推为通用升级。
