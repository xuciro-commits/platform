# ADR-0009 — 已退出的默认桥接包方案

状态：已被 [ADR-0011](0011-apps-interoperate-through-protocols.md) 取代（2026-09-24）。跨应用默认使用协议；CRM 与酒店的专用桥接包已在 #95 删除。

原方案为每对业务包增加直接依赖两端的桥接包，重复协作逻辑随应用组合增长，因此不再作为默认结构。成对专属桥接的允许范围归 ADR-0011；动作、权限和单一权威继续归原应用，跨权威原子性由 [ADR-0026](0026-decisions-across-apps.md) 否决。前端公共视图仍由所属包提供，不在调用方复制。
