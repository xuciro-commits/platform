## 当前主线：平台架构治理与产品化重构

[平台架构治理与产品化重构 SRS/SOW v1.0](Platform-Refactoring-SOW.md) 已正式下达，范围内核查、设计、重构、迁移、清理、验证和交接立即执行，不另等整体立项或逐项开工许可。先完成全局功能、权威与依赖处置，再按完整功能块交付；既有持续 Flow 工作并入项目，保留已有成果及接受条件。技术方案由承接团队负责，执行顺序只在本队列维护。

主线是应用设计台 → 候选测试与发布 → 业务入口 → 运行与诊断。WMS 继续作为受控装配探针，不扩写行业专用应用；不能据此宣称平台已具备完整 ERP/MES 的行业语义。酒店、制造的选定接入→联合发布→普通成员操作→外部投递恢复路线已由现行 `integration-fabric.spec.ts` 串接，发布拒绝定位和原生入口另由 `workspaces.spec.ts` 维护；范围归 ADR-0047 §14，负责人体验认可仍按 Testing。ADR-0082 的测试精简及保留路线对齐已完成；日常环境用 `make local` / `make docker` 一键切换，不再另开脚手架或全量路线迁移任务。

未完成 ADR 先对照代码与后继 ADR：已实现的有界能力修正旧状态；被取代的方案在原状态行注明后继。SRS/SOW §5.2 的最低验收场景及必要依赖属于本项目必做项，下面暂缓表中的相关旧边界不能作为豁免；其余新功能继续按条件触发。编译检查、自动化行为证据、实际业务路线和负责人认可分别表达，不用更改状态行替代实现。
