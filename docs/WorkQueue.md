## 当前主线：未完成 ADR 清理与两行业应用交付闭环

主线是应用设计台 → 候选测试与发布 → 业务入口 → 运行与诊断。WMS 继续作为受控装配探针，不扩写行业专用应用；不能据此宣称平台已具备完整 ERP/MES 的行业语义。当前专注于两行业应用交付闭环。ADR-0082 的测试精简及保留路线对齐已完成；日常环境用 `make local` / `make docker` 一键切换，不再另开脚手架或全量路线迁移任务。

未完成 ADR 先对照代码与后继 ADR：已实现的有界能力修正旧状态；被取代的方案在原状态行注明后继；明确不做或待产品决策的边界保留。编译检查、自动化行为证据、实际业务路线和负责人认可分别表达，不用更改状态行替代实现。
