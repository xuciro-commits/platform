# Proposal

## Why

原生探针已退出，但平台源码仍维护酒店、制造与供暖的专用业务测试、协议参考实现、组织生成器及演练编排。它们让应用维护继续依赖平台程序员。FDE 构建的应用及其验收应属于可编辑资产，平台代码只提供通用机制。

## What Changes

- 删除读取行业包后硬编码行业步骤和预期的 Go、浏览器及部署演练路径；业务验收沿应用包内的原 TestPlan 维护，不另造测试语言或执行器。
- 保留并解耦追加失败、重启、权限及类型检查等通用回归，不以删除应用测试为由删除底层不变量的证据。
- 删除无运行消费者的领域 Go 协议模块与住宿参考应用；包中的声明式协议继续由原平台执行。
- **BREAKING**：移除 Enterprise 内编译的行业组织生成器及专用向导；组织通过原元素、关系和包内受权初始化构建，已保存组织与接受结果不删除。
- 平台部署恢复演练使用独立的通用机制夹具；地址、租户和包选择仍是环境配置。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `platform/application-lifecycle`：应用定义、样本与业务验收归应用资产，源码验证机制而非维护应用。
- `platform/business-models`：组织由显式元素、关系与受权声明构建，不从内置行业分支生成。
- `runtime/deployment`：通用恢复验收不内嵌某个行业应用的业务流程。

## Impact

影响宿主测试、Enterprise 向导与生成 API、领域协议模块、浏览器路线、演练脚本和文档。行业包、现有部署卷、密钥、租户配置、发布内容及业务记录保留。旧输入日志若需要已退出生成器，仍须使用保留的原二进制；本次不改写历史字节或伪造恢复资格。
