# Design

## Context

残留分三类：`declared_*`/`industry_delivery` 等行业业务测试、领域 Go 协议与参考提供方、Enterprise 组织模板和向导。浏览器与部署演练也重复业务步骤。现有包已包含原 TestPlan，原规则与受权写入可独立验证。

## Goals / Non-Goals

清除应用内容在源码中的维护副本，保留通用机制和构建者入口。不新造测试语言、模板执行器或资产目录，不删除部署配置、包、已发布定义和数据；不以修改业务词汇掩盖归属问题。

## Decisions

1. 删除应用业务操作及业务断言；通用 owner 测试直接构建最小合成声明。包内 TestPlan 仍为应用验收权威；缺失覆盖不能冒充已经迁移或通过。
2. 无运行消费者的领域协议 Go 模块整体退出，声明式协议由通用 Protocol/Source/Writeback 机制承担；对应平台协议校验保留独立回归。
3. Enterprise 删除规模/行业生成和 pattern graft 路径。空模型直接使用原 Modeler 的元素、关系和视图操作，现有包初始化继续调用 Enterprise 原动作。已存模型由原接受结果恢复，不新增历史转换。
4. 演练只保留通用发布、迁移、离线关联、观测结果与连续执行的机制证据，使用隔离租户。保留现有基础设施回收与原卷保护。
5. 完成后统一运行受影响 Go/Web 检查、Enterprise 浏览器路线及恢复演练；根据实际证据报告，不再次运行无关全量测试。

## Risks / Trade-offs

退出模板向导属于有意减少平台内置业务。旧输入日志若依赖已退出生成器仍要求保留原二进制；不将已保存模型的纯恢复与旧输入重执行混同。应用测试不再随平台全量测试执行，应用包维护者从原测试入口负责验收。
