## ADDED Requirements

### Requirement: 页面呈现与安全绑定分别冻结

页面 SHALL 随原候选冻结类型化数据、动作、输入及作用域声明和对应不透明呈现字节，依赖投影只消费可验证的原资产绑定。呈现配置 MUST NOT 自行补造查询、动作、文件或权限依赖；视觉数据不透明不能把其他资产或安全声明一起降为无类型内容。

#### Scenario: 候选含有隐藏的执行绑定

- **WHEN** 呈现配置带有类型化声明中不存在的动作、来源或跨资产引用
- **THEN** 该引用不取得执行资格，实际能力请求按原声明和当前权限拒绝
- **AND** 正常作者和导入检查定位不匹配，不能只冻结一段配置便将所需依赖当成已交付。

#### Scenario: 冻结后只更改呈现草稿

- **GIVEN** 一份候选已冻结安全声明与呈现字节
- **WHEN** 构建者修改本地布局或另一份草稿后激活原候选
- **THEN** 正式使用原候选对应的确切字节和绑定
- **AND** 不重新读取最新前端草稿或重新推导原业务版本。

### Requirement: 页面格式迁移保留原件和原执行边界

旧页面 SHALL 以版本化纯投影得到当前安全契约，保留原资产身份、来源版本、修订及内容摘要；新普通作者只写新的声明格式。无法验证映射、未知格式或缺少依赖时 MUST 明确不可用并保留原件，不改写已发布页、候选、包或接受历史，不将漏掉的安全字段转存呈现配置后继续执行。

#### Scenario: 旧页面具有局部集合和历史 Profile

- **GIVEN** 原页面包含受支持的局部输入、查询窗口及其原 profile
- **WHEN** 新实现读取或显式升级该页面草稿
- **THEN** 纯投影保留其确切类型、作用域、动作限制、查询激活及预算；草稿升级另建正常修订与候选
- **AND** 原已发布内容、旧候选与包摘要保持不变，恢复仍遵守原存储格式责任。

#### Scenario: 旧绑定不能无损转为安全契约

- **WHEN** 某旧字段、来源版本或作用域没有可验证映射
- **THEN** 该页面不能继续执行依赖它的任务，用户得到具体不兼容诊断且原件可保留读取
- **AND** 不猜测宽松默认值、不静默删除字段或改用当前最新依赖。
