# Design

## Context

制造业包 mesapp 缺少 groups，停机和工单复合页主要使用 rows。通用导航已有可展开 NavItem，PageDocument 已支持响应式 columns/tabs；原翻译器只读取原生清单和租户词典，声明式应用没有可随发布携带的语言字段。

## Goals / Non-Goals

**Goals:** 应用以自身语言声明、任务分组和主从布局交付；构建者可以从原应用字段/源码编辑这些内容，正式运行只采用已激活版本；既有业务记录继续可读可写。

**Non-Goals:** 不重写工作区视觉系统，不引入无限菜单模型、翻译服务或行业专用 UI，不改业务规则、权限和外部运行条件，不承诺未验收行业业务流程。

## Decisions

1. Application 增加 Languages，使用原 platform.Languages。Build 草稿及原 applicationDescriptor 保留字段；候选摘要、发布映像、恢复和制品继续持有同一原件。校验有界语言和文本，保留缺省空值兼容。
2. 原 setDefinitions 从已发布应用声明派生不可变词典快照并投递给原 translator，同时失效缓存；不从翻译器回读宿主可变状态或建立存储。租户词典最高优先。应用按原 owner 聚合；同 owner 对同一原文给出不同译文时，剔除冲突并回退原字典/原文，绝不依赖装配顺序选择赢家。本轮不支持一个共享资产在两个应用内采用不同译文。
3. 原应用 groups 直接映射到可展开的两级 NavItem；未分组页面继续保持原入口，获权页面过滤与原路由不变。组内不重复渲染应用工厂图标。
4. manufacturing 发布 0.1.2，不覆写已安装 0.1.1。mesapp 提供中文语言声明和五个任务组；停机、工单等复合页使用已有列、标签、权重和尺寸声明，把当前任务与历史/技术来源分开。窄屏沿原容器布局换行。
5. 原包更新不覆盖作者草稿。当前演练应用的呈现字段通过原编辑、候选和激活路径显式更新，业务定义及记录保持；不改 SQL、旧候选或接受历史。

## Risks / Trade-offs

- 语言字段属于声明元数据，翻译读取不得递归改写词典内容、业务值或候选原件；以冻结/恢复及语言切换验证。
- 同 owner 冲突用词回退原文，保留现有文本词典的能力边界，不声称已有任意应用上下文翻译。
- 可见分栏需要足够容器宽度；验收同时观察常用桌面宽度和窄视口，保留原语义选择/查询/动作。
