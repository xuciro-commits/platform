## ADDED Requirements

### Requirement: 记录呈现共享获权引用语义

列表、详情、Inspector、卡片和扩展字段 SHALL 使用原获权记录源呈现引用及多引用；支持解析时显示标题并可进入原记录，尚未解析或不可读时保留 ID 与真实状态。展示缓存的隔离遵守 `runtime/access-control` 的浏览器派生读取要求。只读预览、企业关闭元素、工作任务的处理入口及复制导出的原值 MUST 保留各自原语义。

#### Scenario: 从详情打开正向引用

- **GIVEN** 一条获权记录包含可读的单引用、多引用或企业元素引用
- **WHEN** 用户依次在列表、详情、Inspector 和卡片查看该字段
- **THEN** 各处按同一引用语义展示，并可打开原获权记录
- **AND** 不要求用户复制 ID 到另一列表，也不把显示标题写回业务字段。

#### Scenario: 引用名称改变或读取失败

- **WHEN** 原记录名称改变，或当前读取不能取得名称
- **THEN** 各呈现随原读取更新，失败显示可解释状态或原 ID
- **AND** 不建立另一套名称事实源，不因一次失败永久停止解析。

#### Scenario: 本地样本引用不跨入正式环境

- **GIVEN** 页面预览使用本地样本记录和样本引用
- **WHEN** 详情或卡片呈现该引用，用户尝试打开它
- **THEN** 只使用原本地读取和允许的导航范围，不请求正式记录或打开正式 Inspector
- **AND** 获权正式记录的打开能力不能仅因复用同一组件而赋给样本源。
