# Design

## Context

目标见 [proposal](proposal.md)。核对基线为 `d5d5c817`。Gemini 的源码基线较早，部分数量、入口与兼容结论需要纠正；本 change 采用已核实的职责减法，不以预计删除行数衡量完成。

| 报告判断 | 当前证据与决定 |
|---|---|
| 页面校验混有树/查询、字段隔离、端口、实体字段和专属语义 | 成立；`page_widgets.go`、`page_loop.go` 及各 `page_*.go` 已核对。前几类可共享声明，不删除真正的核心和专项语义。 |
| 序列化后检查 authoringFields 子集即可完全替换 | 不成立；非指针 AssetRef 零结构仍编码，空集合和非 nil 指针也有不同语义。以原字段定义识别实际配置，不用 JSON key 是否存在代替是否配置。 |
| 五个新属性足够承接所有约束 | 不成立；条件端口、共享选择、同源 measure、嵌套绑定和各类 owner 有差异。只声明确实可复用的规则，例外保留在明确的专项检查。 |
| 历史 Profile 只是新组件开关 | 不成立；`v2.97` 还影响查询激活和预算。保持原顺序与门槛，当前代码已经说明普通增量不升全局 Profile。 |
| Builder、Data Connection、Agents 只是三个作者入口 | 部分成立；后两者还由 Platform 贡献治理视图，`composeApplications` 按同 ID 合并，不能删除其原运行角色。 |
| 对象十二区段可以简单变四区 | 可分层，不能把 Lifecycle 与 Actions 隐去。采用结构、行为、规则与访问、数据与预览；旧区段仍可定位。 |
| 原型导入器已无有效消费者 | 不成立；存在三个生产入口、Catalog、浏览器路线和原生 Go 样本。负责人已确认放弃该来源迁入，完整删除适配器并迁移仍有价值的原生页面验证。 |
| 固定 Wasm 可以用普通规则聚合替代 | 不能直接替代；规则层消费外部摘要而非计算该 f32 ABI。可以逐操作保持数值语义改为 Go，去掉固定实例装配。 |
| Continuous Flow 可只保存小累加器 | 不成立；原始行承担去重、迟到重开、滑动过期与死信。64 MiB 是上限，不是每批固定分配；保留现存 Frame 与 GC。 |
| 给 Observation 加迟滞只是提取函数 | 不成立；需定义清除、乱序、拒绝、重启和状态权威。本轮保留原 Flow episode 及 Observation 的逐窗口声明，不增加隐式状态。 |
| 在线租户格式 3 后可删 SQL 1/2 修补 | 不成立；旧备份、首次转换及完整日志恢复仍可达，且正常格式 3 已快速退出。保留这段有明确责任的兼容读取，不新建“固化平台”。 |

## Goals / Non-Goals

**Goals:** 新组件只在原清单声明普通规则；作者在一个应用上下文完成跨域任务；原路径替换后删除对应重复实现；固定统计不再创建 Wasm 实例。

**Non-Goals:** 不裁剪企业/UAF、改变内核或 AssetKind，不扩大权限、跨权威事务或发布闭包，不重建页面 JSON 和保存数据，不做 Observation 的新状态机、连续存储改版或历史日志截断。

## Decisions

### A. 在现有 Widget 清单集中可重复规则

沿 `pageui/widgets.json`、原 `ValueSchema` 与 `authoringFields()` 扩展，不另建 Schema、注册表或通用任意规则语言。字段归属使用同一清单；零结构与空集合按原语义视为未配置，非 nil 指针保持其已配置含义。无 Document 的旧平铺格式继续按冻结名单读取。

端口声明覆盖常见模式、owner、组合和计划约束，Loop 引擎继续负责树归属、深度及预算，端口规则消费引擎计算的上下文。实体字段角色使用原授权后 `EntityInfo`；不能换成更宽的模型目录。移除被声明完整承接的互斥、类型和逐组件作用域分支，不保留同一普通规则的两套实现。

保留 Observation 四模式与共享资产对齐、多跳模型和矩阵表达式、生命周期、行内动作签名与审批、子页闭包、图关系、空间 GLB、AI/Compute 签名、精确刻度等专项。Gantt 颜色与状态选项、analysis 步骤与分类选项、统计 measure 和查询来源也保留专属关系检查。

保持 `v2.1–v2.111` 的原识别和顺序、当前 UIProfile、组件 configVersion 与存储格式。把全部旧档映射最新档或直接提升组件版本都可能拒绝或误接受旧页面，本轮不采用。

### B. 一个作者上下文，五个工作域

将 Build 自己贡献的集成和 Agent 定义视图纳入 `build`；Platform 的 Data Connection / Agents 运维贡献保持原 owner 和授权。用一份工作域描述派生全局菜单、项目树、创建选择和 route 分类，资产仍由原 `resources` Kind 与后端资产身份决定。对象只归 Model，Logic 的对象行为入口定位同一对象的行为区。

Integrator 可进入原集成编辑范围，但不复用需要读取全部 Builder 草稿的项目主页。运行模型、草稿缓存隔离和撤权行为沿 `useAuthoringModel`；Publisher 与 Agent 运行角色不因导航改变而扩大。应用 ContextBar 和项目树按当前任务选择库存，不在侧边栏读一套、顶栏又读全部草稿。

保留原视图 ID 和 URL 参数。旧 `behavior/assemble/verify` 在入口解析到新域；`assemble` 根据实际资源定位 Logic 或 Integration。对象旧 `tab`、字段、动作、权限定位进入新主区内的原内容，同一对象重新定位不通过 React key 重建草稿。原生扩展继续使用已有 entry/extends/replacements 解析。

对象使用四个主区及各自必要的二级内容，沿原 ContentTabs、Workbench 和 useObjectDraft；不新建 Shell、不改变视觉系统、不删除高级行为。英文与中文同步，错误和未应用源码仍阻止保存。

### C. 固定统计用原语义实现，连续工作保留原 owner

固定标识 `wasm:f32-window-stats` 保留为已发布历史数值语义标识。Go 实现继续按 f32 输入/阈值、顺序 f64 累加及 f32 输出处理，保留空窗口、输入上限、非法值和输出溢出条件。沿既有准备上下文提供取消与执行预算，不新增超时后台 goroutine 或备用计算路径。

删除仅用于固定核的 embed、初始化与实例，以及失去消费者的 WAT/Wasm 制品；原通用受控 Wasm 能力仍需要 wazero，依赖保留。滑动窗口、游标、水位、迟到策略、死信、Frame 引用及 GC 不受此实现替换影响。

### D. 删除旧原型适配能力

SourceModule 不是原生 Page，StructuredEditor 不是其等价转换器。负责人已确认不再接收 Next.js 原型的私有 JSON；删除三个入口和整块适配实现。原两条导入路线改由平台原生 Page 建立与编辑，保留独立卡片字段、原动作、notice/overlay、拒绝、草稿和发布断言。仅迁移器专用 Go 样本测试退出；平台原生 Page 的复杂验证继续并脱离外部模型 fixture。已保存的原生草稿与运行数据无需转换。

## Risks / Trade-offs

- 集中规则误收紧合法页面或漏掉安全限制 → 保留既有页面样本和拒绝场景，整块后运行全部页面 owner 检查及共享清单生成检查；不改断言消除失败。
- 五域重组遗失原动作或草稿 → 全部旧内容明确归位，保留老 URL 与区段定位，通过完整应用路线检查往返与发布。
- 导航可见性扩大草稿或运维访问 → 原角色、端点与获权模型不变，单独检查 Integrator、Publisher 与 Agent 运维身份。
- 本机统计改变数值 → 原有 f32 反例、空窗口及拒绝检查保留，不能只测试普通小整数。

## Migration Plan

本轮在原格式和版本上直接替换共享实现，无数据库迁移或永久双写。原作者视图 ID 继续识别，老工作域与对象区段只在输入边界映射，不长期保留第二套作者导航。旧私有格式迁移器不保留备用适配器。完成后将规范差量同步到既有模块、更新 Architecture 实际组织并移除本次队列条目。

编码中只做必要编译；整块统一运行 Go 构建/边界、相关页面与 Flow owner、Web 类型与相关包测试、对应浏览器任务和规范检查。代码提交到 main 后按原脚本更新两宿主，保留数据卷；完整部署演练在同一交付节点跑一次，不拿局部绿测替代。
