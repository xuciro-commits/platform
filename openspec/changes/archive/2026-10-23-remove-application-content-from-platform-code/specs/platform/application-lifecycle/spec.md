# Spec Delta

## ADDED Requirements

### Requirement: 应用业务验收与平台机制测试分别归属

应用的业务定义、样本与业务验收 SHALL 作为原受控资产由构建者编辑、执行和移交。平台源码 MUST NOT 通过专用测试、模拟提供方或启动工具维护某个行业应用的业务流程；平台机制测试使用独立最小声明验证通用不变量，不依赖安装某个行业包才能证明正确。

#### Scenario: FDE 修改应用业务规则

- **WHEN** FDE 修改并发布应用规则及其验收计划
- **THEN** 通过原应用测试与发布入口维护验收，不修改平台 Go、TypeScript 或 Python 测试
- **AND** 包文件只是原资产的可移交表示，不获得另一套运行或验收权威

#### Scenario: 清理行业业务测试

- **WHEN** 平台退出内嵌行业业务测试
- **THEN** 保留应用包中的验收资产、运行数据和定义
- **AND** 追加失败、重启恢复、权限与类型约束继续由独立的平台机制回归验证
