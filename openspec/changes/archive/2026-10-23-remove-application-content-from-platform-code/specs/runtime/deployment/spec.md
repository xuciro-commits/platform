# Spec Delta

## ADDED Requirements

### Requirement: 平台演练不内嵌行业业务编排

平台的部署和恢复演练 SHALL 使用独立的机制夹具验证发布、迁移、在途工作、保存结果及租户隔离。行业包、应用任务与验收计划由原构建资产提供，MUST NOT 在演练脚本中维护专用酒店、制造或供暖业务步骤；运行实例名称与端口作为部署配置不因此删除。

#### Scenario: 不安装行业包执行平台恢复演练

- **WHEN** 在隔离环境执行原平台恢复演练
- **THEN** 可验证重启、数据库备份恢复、旧请求和在途版本接续
- **AND** 不创建酒店预订、制造工单或供暖告警来替代机制夹具
