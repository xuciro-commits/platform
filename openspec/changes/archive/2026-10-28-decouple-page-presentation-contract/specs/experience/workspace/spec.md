## MODIFIED Requirements

### Requirement: 页面契约唯一来源与版本兼容

系统 SHALL 使页面运行渲染、作者注册、普通属性与视觉配置检查消费同一呈现清单；宿主仅解释类型化数据、动作、输入与作用域声明及有界不透明呈现字节，不依赖具体视觉组件。未知组件、配置版本或不兼容 profile MUST 保留原配置并在作者、导入及渲染入口明确拒绝使用或要求兼容处理，不静默删除后保存。旧页面与 profile 的解释不因重整改变；安全绑定仍由原宿主独立检查。

#### Scenario: 打开包含未知组件配置的旧页面

- **GIVEN** 保存页面包含当前渲染器不支持的组件版本
- **WHEN** 构建者检查页面兼容性或尝试升级
- **THEN** 系统定位不支持的配置并保留原值，不能把组件丢弃后当成成功转换。

#### Scenario: 组件带有另一个组件的配置

- **WHEN** 页面组件携带呈现清单未声明且实际已配置的属性或端口
- **THEN** 正常作者、导入及渲染入口使用同一清单拒绝该配置，不依赖另一个组件的校验函数被偶然调用
- **AND** 零值结构、空集合及非空配置指针按原读取语义处理，不误拒原合法页面；直接发布 API 只核对类型化安全声明和字节边界，不将保存成功说成视觉合法。

#### Scenario: 绑定逃逸或查询窗口不合法

- **WHEN** 端口读取其他局部 owner 的变量，或其查询排序、窗口及来源不满足原约束
- **THEN** 宿主拒绝对应类型化声明，实体字段检查继续使用原获权模型
- **AND** 即使呈现字节省略或隐藏该引用，原查询图预算、窗口乘法展开、动作签名或跨资产身份检查也不能绕过。

#### Scenario: 普通属性扩展不改变历史 Profile

- **GIVEN** 旧页面使用一个受支持的历史全局 Profile
- **WHEN** 当前组件增加向后兼容属性或视觉检查迁至呈现 owner
- **THEN** 新旧页面保持各自原版本的查询激活、预算和能力门槛
- **AND** 不把旧 Profile 当成最新档，不为普通增量再增加全局版本，也不直接提高组件版本排除旧配置。

### Requirement: 已发布应用的获权声明使用所选语言

工作区及正常应用发现、页面读取 SHALL 复用原翻译器呈现已发布应用提供的语言文本，覆盖菜单、页面、字段、动作及说明。租户明确覆写 MUST 优先于应用词典；同一 owner 的多个应用为同一原文提供冲突译文时 MUST 回退原字典或原文，不按注册顺序覆盖。宿主只翻译类型化声明元数据，不递归改写不透明呈现字节；Web 原呈现 owner 消费同一已发布应用的有效词典投影，只展示声明文本译文，不重新实现覆写与冲突规则。翻译不能改变英文原件、候选字节、业务数据或读取权限，草稿词典不得影响正式运行。

#### Scenario: 切换应用界面语言

- **GIVEN** 应用已发布英文原文和中文语言声明
- **WHEN** 获权成员在英文和简体中文间切换
- **THEN** 菜单、页面和字段呈现对应语言，记录 ID、业务文本及原动作身份保持不变。

#### Scenario: 租户覆写及应用冲突

- **WHEN** 租户覆写应用用词，或同 owner 的两个应用提供冲突译文
- **THEN** 租户覆写优先；没有覆写的冲突文本保持原字典/原文回退
- **AND** 更新发布后不会复用过期词典缓存；不透明呈现使用同一已解决结果，不能在 Web 另选赢家。

#### Scenario: 冻结后切换不透明呈现的语言

- **GIVEN** 候选已冻结应用词典和英文呈现原件，随后词典草稿已经修改
- **WHEN** 用户在正式页面切换中英文
- **THEN** Web 按原呈现清单仅对标题、说明等声明文本消费原发布的有效词典，宿主继续翻译其类型化元数据
- **AND** 记录业务文字、状态代码、英文原件及原候选字节均不变，未发布词典不进入正式显示；不新增语言服务、词典存储或管理员读取资格。

## ADDED Requirements

### Requirement: 不透明页面呈现不能携带执行权限

页面的呈现字节 SHALL 只能引用已声明的获权数据、触发、输入与作用域身份；记录、字段、查询、动作、文件及外部资源的实际访问继续由原 owner 决定。未声明或被当前权限过滤的绑定 MUST 不可通过呈现配置补造，不得从客户端可见性推导授权。

#### Scenario: 呈现配置伪造查询或动作

- **WHEN** 不透明配置携带没有类型化声明的对象、敏感字段、额外动作或文件引用
- **THEN** 正常运行器不建立该访问，直接请求仍由原宿主拒绝
- **AND** 配置被隐藏、折叠或标为未使用不能改变原作用域、完整性与展开预算。

#### Scenario: 当前权限过滤数据来源

- **GIVEN** 原页面仍保留某个组件及其字节，但成员已失去其数据来源权限
- **WHEN** 工作区刷新当前投影
- **THEN** 该组件不能取得失去资格的绑定，依赖它的输入和结果按原传递规则失效
- **AND** 原发布字节、其他获权组件和用户未完成输入继续按原会话规则保留。

### Requirement: 页面本地联动不形成正式业务结果

页面纯联动 SHALL 使用同源版本化规则和明确的获权快照、用户输入、时间与主体，保留缺失、不可读、不完整及错误状态。模块不可用时 MUST 明确报告，不能默认为零、调用云模型代算或把本地结果当作正式授权、预留与持久接受；实际提交仍经原宿主重新决定。

#### Scenario: 联动输入缺失或规则模块不可用

- **WHEN** 表单缺少原获权输入，或浏览器不能初始化相容规则模块
- **THEN** 显示对应未知、缺失或失败，原输入保留
- **AND** 不给出假定成功的业务计算，也不产生隐式外部模型请求。

#### Scenario: 浏览器算出结果后服务器事实改变

- **GIVEN** 浏览器已显示一次纯计算结果，正式事实或成员资格随后变化
- **WHEN** 用户提交原动作
- **THEN** 宿主按当前获权事实、原动作版本及规则重新决定
- **AND** 浏览器结果不能覆盖拒绝、陈旧修订或不完整集合。
