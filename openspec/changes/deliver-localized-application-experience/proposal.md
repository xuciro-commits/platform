# Proposal

## Why

已发布 MES 虽可完成交付和记录操作，但菜单中英混排、17 个页面平铺、主列表与详情全部纵排，尚不满足业务使用者的基本呈现要求。原平台已支持页面布局和分组，需要补齐可随应用发布的翻译声明并正确使用现有能力。

## What Changes

- 应用携带有界语言词典，沿原草稿、候选、激活和恢复保存；复用原翻译器，业务值和身份不翻译。
- 应用菜单使用原分组形成可展开的两级导航，当前页面及其所属组可定位；未分组应用维持原入口。
- 制造业包新版本提供完整中文声明、按任务组织的分组及工单/停机的主从分栏，历史与技术来源放在次级标签内。
- 以已发布 MES 实际升级、切换语言和页面操作验收；保留已创建业务记录和原版本。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `platform/application-lifecycle`：应用语言声明随确切候选交付，原版本和历史不重写。
- `experience/workspace`：获权声明本地化、可展开分组及主次布局共同形成正常应用入口。

## Impact

涉及 Application 描述与 Build 映射、原翻译器的发布声明投影、工作区导航及制造业包 JSON。无新执行器、翻译服务、授权机制或存储；不更改行业规则、业务数据和外部连接要求。
