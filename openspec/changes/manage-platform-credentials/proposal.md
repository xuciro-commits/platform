# Proposal

## Why

提供方只能新增和删除，更换地址或密钥会丢失模型启用配置。现有密钥解析虽共用于 AI 和集成，但只有环境变量或挂载文件，没有租户级托管、使用绑定和构建者入口。

## What Changes

- 在原平台治理 owner 增加通用凭据元数据、加密托管、部署引用、版本替换及停用，绑定具体消费者与目标地址，不公开原值。
- 在线密钥录入先加密，再通过原提交保存密文与元数据；普通业务提交、离线队列、包与日志不接收密钥明文。
- 增加提供方编辑与检查，保留 ID、已启用模型及历史；AI、连接器和外部投递复用凭据解析。
- 补齐双语凭据管理界面、提供方凭据选择及录入，并同步 Architecture 与部署密钥操作。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `runtime/access-control`：凭据归属、加密录入、租户隔离和按用途使用。
- `platform/ai-knowledge`：提供方编辑与检查，以及引用通用凭据。
- `platform/integrations`：连接在目标环境绑定平台凭据，仍保留逻辑定义与实际秘密分离。

## Impact

涉及 Console 接受状态、共用秘密解析、AI 动作、在线录入接口、治理与 AI 页面、生成 API 类型和本地配置。不新增数据库、身份提供方或执行器；不实现 OAuth、外部 Vault/KMS 适配或主加密密钥轮换。本次先覆盖 API key、Bearer 和密码；已有部署引用保留，应用发布及历史不重写。
