# 文档与代理配置

- 遵守 docs/README.md：`docs/` 只有十份文档，按问题分；不新建文档，新内容写进已有的某一份。
- 写目标，不写现状。进度只写在 docs/plan.md，做完的行删掉。不写差距清单、历史、总结。
- 一个事实只在一处，别处链接。只写代码里读不出来的东西；冻结的东西不写文档。
- 短句，常用词，一行一件事；一行不超过 200 个字。
- 预算由 `make check` 核对：每份文档 250 行，plan 150 行，`AGENTS.md` 120 行，路径规则 40 行，技能 150 行，代理定义 60 行。
- 报告、审计、评审、方案、任务分解不入库。
- 改意图（docs/intent.md）与增加文档，是负责人的决定。
